Prompt（系统提示词）。这段指令决定了模型的语气、边界、可用工具、处理流程、是否联网、如何拒绝有害请求，甚至怎么组织内部推理。对用户而言，它完全是黑箱；对研究者与开发者而言，又是关键的「原始数据」。动态与多变： AI 厂商几乎每周都在调整模型和界面，随之更新 System Prompt。想长期追踪，需要有人持续抓取、归档、版本化。这完全不是一次性工程，而是一个长期维护的「标本馆」。信息不对称： 厂商通常不会完整公开这些内容；就算公开，也多是摘要或原则说明，而不是「逐字逐句」的原始 Prompt。这导致开发者想借鉴最佳实践、研究者想分析安全边界时，缺少权威的一手材料。安全与合规研究需要： 研究与安全社区需要了解「系统是如何被约束的」，才能评估现实世界中的抵抗攻击、越狱与提示词注入风险。把真实的 System Prompt 做成公开、可引用的资料库，为这方面的研究提供了基础设施。这个仓库的本质，就是把「本不可见的规则」变成「可读、可比较、可追溯」的公共数据集。它不只是“泄露”，而是长期、系统化地采集与归档。核心亮点与功能剖析一、广度与系统性：覆盖头部厂商与产品矩阵厂商覆盖包括 Anthropic（Claude 系列与 Code、Design、Cowork
