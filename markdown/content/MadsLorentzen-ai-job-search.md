# ai-job-search：让你自己的 AI 找工作，从 69 封申请到 1 份 Offer 的开源奇迹
> 一句话总结：这是一个将你的 Claude Code 变身**全栈求职助手**的开源框架，它帮你自动抓取岗位、评估匹配度、定制简历和求职信，并准备面试——所有过程都在本地运行，数据完全归你所有。
## 🧠 一、背景与痛点：求职者的“数字军火”
现代求职早已不是“投一封简历等一个回复”的时代。它更像一场**精准的战役**：需要系统性地研究公司、针对每个JD（职位描述）定制材料、跟踪多个申请状态、并持续准备可能长达数轮的面试。这个过程繁琐、重复，且极易产生疲劳感，导致很多求职者草率行事，错失良机。
Mads Lorentzen，这位训练有素的地球物理学家，在2025年底遭遇裁员后，**亲身体验了这种痛苦**。他没有选择传统方式，而是发挥技术背景，构建了一套为自己量身定制的AI求职自动化流程。这套流程不仅帮他成功在2026年6月转型成为AI工程师（**69封定制申请、20次首面、1份录用**），最终被他开源，变成了现在的 `ai-job-search`。
它的核心痛点解决思路很简单：**将重复性、模板化的脑力劳动外包给AI，而将需要创造性和人类判断的部分保留给自己**。这不仅仅是“节省时间”，更是让整个求职过程**系统化、数据化、可追踪**，从而极大提升求职效率和成功率。

`ai-job-search` 的强大在于它构建了一个**完整的、闭环的求职工作流**，其核心能力可以概括为以下四个方面，通过下面的流程图可以一目了然：

### 1. 🎯 智能岗位评估与匹配（/scrape & /apply）
这是项目的**核心灵魂**。它并非简单地“扔给AI一个JD”，而是基于一个**预先设计的、结构化的评估框架**（Rubric）。
-   **如何工作**：当你使用 `/scrape` 命令时，它会利用内置的脚本（通过Bun运行）**自动爬取多个主流求职网站**（如丹麦的Jobindex、Jobnet，以及通用的LinkedIn搜索等）的岗位信息，并根据你的个人资料进行初步匹配和排序。当你对某个具体岗位使用 `/apply` 时，系统会启动其“**评估-起草-审查-修订**”的完整流程：
    -   **评估（Evaluate）**：基于预设的评分维度（如技能匹配度、公司前景、文化契合度、薪酬范围等），对目标岗位进行深度分析并给出一个**匹配度评分和详细评估报告**。
    -   **起草（Draft）**：根据评估报告和你的个人资料，AI会**自动起草一份高度定制化的CV和求职信**。CV采用LaTeX格式生成，确保排版专业且ATS友好（能被招聘系统良好解析）。
    -   **审查（Review）**：这是项目的一个精妙设计。它会启动第二个“**审查员Agent**”，以批判的眼光审视起草的材料，指出其中的弱点、矛盾或不匹配之处，并提供修改建议。
    -   **修订（Revise）**：综合审查员的建议，AI会对材料进行最终修订，并输出一份高质量的、可直接提交的PDF版CV和求职信。
> 💡 **比喻**：这就像拥有一支**虚拟的求职咨询团队**。一个分析师负责调研并给你提供详细的岗位分析报告，一个文案专家根据报告写初稿，一个严格的编辑负责挑刺和修改，最后由你这位“总编辑”终审把关。
### 2. 📝 系统化面试准备（/interview）
获得面试机会只是第一步，`ai-job-search` 还能帮你**高效准备每一场面试**。
-   **如何工作**：使用 `/interview <company>_<role>` 命令，系统会：
    -   调用该岗位的**完整申请档案**（包括原始JD、你提交的CV和求职信、以及之前记录的反馈）。
    -   通过网络研究公司和面试官的背景信息（遵循“**验证后再使用**”的原则，避免幻觉）。
    -   根据岗位要求，**预测可能的面试问题**，并将你的项目经历和技能通过 **STAR法则**（情境-任务-行动-结果）进行匹配，生成有针对性的回答框架。
    -   提供一个**角色扮演式的模拟面试**，让你可以提前练习。
### 3. 🔄 全流程跟踪与反馈（/outcome & /notion-sync）
求职是一个需要不断学习和调整的过程。`ai-job-search` 提供了强大的**跟踪和反馈循环**。
-   **如何工作**：使用 `/outcome <company>_<role> <status>` 命令，你可以记录每个申请的最终状态（如面试邀请、offer、拒信、无音信）。系统会：
    -   将该岗位的所有相关材料（JD、CV、求职信）归档到 `documents/applications/<company>_<role>/` 目录下，形成完整的申请历史。
    -   更新一个集中式的**申请状态追踪器**。
    -   **基于这些真实的反馈数据**，系统会建议你运行 `/setup` 来**重新校准和优化你的个人资料和评估框架**，从而让未来的搜索和申请更精准。
    -   可选地，通过 `/notion-sync` 命令，可以将整个申请流程**同步到你的Notion数据库中**，提供一个方便的可视化概览。
### 4. 🔒 本地优先与数据隐私
这是该项目**最值得称道的理念之一**。整个流程在你的**本地机器和GitHub仓库**上运行。
-   **你的数据完全归你所有**：所有个人资料、申请材料、跟踪数据都存储在你自己控制的代码仓库里。你不需要将敏感信息上传到任何第三方云服务。
-   **可审计与可定制**：你可以审查每一行代码，修改任何提示词、评估标准或工作流，将其完美地适配于你自己的行业、国家或个人风格。
-   **无付费陷阱**：项目明确声明**无任何加密货币、代币或付费赞助计划**，支持方式仅为Ko-fi打赏和GitHub贡献。

**🔍 简要解读**：
-   **`ai-job-search`** 更像一个**为个人求职者打造的“瑞士军刀”**，它提供了一个**高度集成、开箱即用的完整工作流**，特别适合希望**在一个框架内解决从搜索到面试所有问题**的用户。其**双Agent协作模式**和**面试模拟功能**是显著亮点。
-   **`career-ops`** 则更像一个**“可编程的求职工厂”**，它提供了**更精细、更底部的操作模式**，适合**技术能力更强、希望深度定制自己求职流程**的用户。其在**大规模门户扫描**和**自动填写申请表**方面能力更强。
**✨ 独特竞争力**：`ai-job-search` 的独特竞争力在于其**极其清晰的“人类在环（Human-in-the-loop）”设计哲学**和**优秀的开发者体验（DX）**。它从不声称“为你自动申请”，而是强调“**为你精心准备材料，由你最终决策和提交**”。这种设计既保证了效率，又避免了伦理风险，让求职过程始终在你的掌控之中。
## ⚠️ 五、局限与不足：它不是银弹，也有“坑”
1.  **技术门槛与初始设置成本**：这是最大的门槛。你需要：
    -   安装并配置 **Claude Code**（需要Anthropic API Key或订阅）。
    -   安装 **Python 3.10+** 和 **Bun**。
    -   安装 **LaTeX** 发行版（如TeX Live、MacTeX）并确保能编译 `lualatex` 和 `xelatex`。
    -   可选安装 `pdftotext` 以获得更好的ATS解析检查。
    这对非技术背景的用户来说可能是一个不小的挑战。
2.  **地域性限制**：项目内置的岗位搜索脚本是为**丹麦市场**优化的（Jobindex, Jobnet等）。虽然其模式可以扩展到其他国家，但这需要你自己编写或修改相应的爬虫脚本，对普通用户而言不现实。不过，对于中国用户，可以主要依赖其**LinkedIn搜索**和**手动粘贴JD**的功能，核心的评估和申请材料生成功能是通用的。
3.  **依赖外部服务的稳定性**：岗位搜索功能依赖于目标求职网站的页面结构。一旦这些网站更新了UI或反爬机制，内置的脚本就可能失效，需要等待社区修复或自行修改。
4.  **并非“一键投递”**：项目**绝对不会自动为你提交申请**。它只负责准备材料，最终的决策和提交动作必须由你亲自完成。这既是优点（安全、可控），也可能是缺点（对于追求极致自动化的用户而言）。
5.  **成本考量**：虽然项目本身免费开源，但使用它需要消耗 **Claude API 的调用次数**。如果你的求职周期很长，申请岗位非常多，**API费用可能会是一笔不小的开支**（需根据你的订阅计划计算）。你可以考虑使用本地模型来降低成本，但这会牺牲一定的智能度。

### 行动建议
#### 🎯 如果你决定尝试，请按以下步骤操作：
1.  **确认前提条件**：确保你有一台能运行命令行的电脑（Mac, Linux, WSL），愿意折腾环境配置。
2.  **开始初始设置（预留1-2小时）**：
    ```bash
    # 1. 安装 Claude Code (参考官方文档)
    # 2. 安装 Bun (https://bun.sh)
    # 3. 安装 LaTeX (推荐 MacTeX 或 TinyTeX)
    # 4. Fork 并克隆项目
    gh repo fork MadsLorentzen/ai-job-search --clone
    cd ai-job-search
    # 5. 安装项目依赖
    for tool in jobbank-search jobdanmark-search jobindex-search jobnet-search linkedin-search freehire-search; do
      (cd .agents/skills/$tool/cli && bun install)
    done
    ```
3.  **配置你的个人资料（关键步骤）**：
    ```bash
    claude
    # 然后在 Claude Code 中执行：
    /setup
    ```
    根据提示导入你的CV、LinkedIn资料或通过对话式问卷创建你的个人档案。**这一步投入的时间越多，后续输出的质量就越高。**
4.  **尝试第一次搜索**：
    ```bash
    /scrape
    ```
    查看返回的岗位列表和匹配度评分，感受其评估框架的深度。
5.  **为第一个心仪岗位生成申请材料**：
    ```bash
    /apply <job_url>
    # 或者直接粘贴JD
    /apply <paste_job_description_here>
    ```
    仔细阅读生成的评估报告、CV和求职信，并根据“审查员”的建议进行最终修改。
6.  **探索其他功能**：获得面试后，尝试 `/interview`；记录申请状态后，尝试 `/outcome`；如果想同步到Notion，尝试 `/notion-sync`。

-   **技术爱好者**：**强烈推荐**。这绝对是一个值得你花时间学习和定制的“玩具”，能极大提升你的技术能力和求职效率。
