# Veyra-NRVideo 深度评测：把 DLSS 5 带进视频播放器与主机采集的开源小钢炮
## 一句话总结
**Veyra 是一款把 NVIDIA DLSS、RTX Video SR、神经降噪、AI 补帧、PS5 串流、采集卡实时预览"全打成一个包"的开源 Windows 视频增强播放器，堪称"小黄鸭 Lossless Scaling 的视频播放器版 + 主机串流增强版"，是目前唯一能把 PS5 主机画面通过 DLSS 5 推到 120FPS 的本地开源方案。**
GitHub 项目地址：https://github.com/Likely7/Veyra-NRVideo（当前版本 1.4.4 / 2.0.8，2026 年 11 月仍在高频更新）
---
## 背景与痛点：为什么会有 Veyra？
要理解 Veyra 的诞生逻辑，得先看清它针对的几个"老大难"场景。
**痛点 1：老片源画质"原地踏步"。** 30 年前的电影、PS2 时代的老游戏录像、低码率追剧片源，放到 4K 显示器上糊成一团，传统播放器顶多做一下 Lanczos 拉伸，依然救不了。
**痛点 2：低帧率片源"看着难受"。** 30fps 的电影、24fps 的老动画、60fps 的主机采集，在 120Hz/144Hz 高刷屏上拖影明显。业界主流方案是 SVP（付费）、RIFE（折腾）、Lossless Scaling（通用游戏向），但都各有短板。
**痛点 3：主机画面"用不上去画质特效"。** PS5 主机原生 30fps 锁帧，画质锁死，DLSS/NR 这些 PC 专属的 AI 画质特性根本碰不到主机。唯一入口就是采集卡——但采集卡软件生态一潭死水。
**痛点 4：工具链"散装"。** 想做"超分 + 降噪 + 补帧 + HDR + 导出"五件事，得 MPC-HC + madVR + SVP + HandBrake 来回折腾，参数互不打通。
Veyra 的作者 Likely7 在 GitHub 与 B 站（@Likely7Ai）以"硬件实测 + 持续打磨"的方式，把这套分散的链路收成了一站式工具，并在 docs/ 目录公开了大量逐版本实测数据——这是它区别于一般玩具项目的硬核之处。

## 核心亮点与功能剖析
### 亮点 1：四大增强模块同链路组合，可以"叠 buff"
Veyra 用一条统一的 D3D12 处理管线，把以下能力按需串联：
| 模块 | 实现方式 | 适用场景 |
|------|---------|---------|
| **超分辨率 SR** | DLSS SR / RTX Video SR / XeSS / FSR | 1080p 片源拉 4K、8K，老片翻新 |
| **NR 神经降噪** | NVIDIA 原版 / RTX 40/50 社区版 / RTX 30 兼容实验版 | 暗部噪点、压缩块痕、胶片颗粒 |
| **补帧 FG** | DLSS Frame Generation / XeSS / Smooth Motion（驱动侧） | 30fps 老片→120fps、主机 30fps→120fps |
| **HDR** | HDR10/PQ/HLG 直通，HDR→SDR 色调映射 | PS5 HDR 串流、HDR 影片预览 |
**处理顺序默认"超分→NR→补帧"**，"低延迟模式"可切换为"NR→超分→补帧"，UI 上有四个独立阶段卡实时显示 GPU 耗时，让你一眼看清瓶颈在哪一段。
> **关键洞见**：Veyra 的杀手锏不是某一项单一功能，而是"模块化组合"——它允许你只开 NR 不开补帧、只开超分不开 NR、或者全开压榨 GPU，每一段都能在 UI 上独立调节。
### 亮点 2：PS5 串流 + 增强链 = 主机版"DLSS 5"
这是 Veyra 最具话题性的能力。它内置了基于 chiagi-ng 的 PS5 Remote Play 串流支持，本地解码 H.264/H.265 后直接进增强链，码率请求 5–100Mbps，最多可推到 4K 超分 + 4X 补帧。README 直接打出了"Bring PS5 GTA6 to 120FPS with DLSS 5"的硬核标题。
社区用户 RevolutionaryBus8208 在 Reddit 上展示了完整方案：PS5 → 4K 采集卡 → PC Veyra（DLSS 5 神经渲染）→ 帧生成 90fps → 4K 电视，验证了"主机独占大作也能蹭到 PC AI 画质特效"这条路。
### 亮点 3：节点模式（Node Mode）——把处理链做成可拖拽的积木
2.0 版本引入的节点模式是 Veyra 的"工程师浪漫"：在画布上像 DaVinci Resolve 一样拖拽节点、连线，自由编排属于自己的超分 + 去噪 + HDR 工作流，并实时看到每段的处理效果与 GPU 耗时。节点不是示意图，**连线即真实处理链**。
### 亮点 4：极硬核的发布与边界文档
这是它区别于"个人小工具"的最大差异点。每个版本 Release Notes 都会明确写"已验证"和"边界"两栏，比如 1.2.0 中明确标注：
> "RTX 5070 已验证 HDR GPU 处理…真实 HDR 屏观感、5.1 扬声器定位、不同采集卡、PS5 HDR 与 RTX30/40 实机仍需各自验收。NR / RTX Video SR 的 HDR 路径是 SDR 代理与保留 HDR 基底合成，不是原生 HDR 模型推理。"
这种"不吹不黑、把话说死"的发布风格在开源社区里相当少见，对重度用户非常友好。
### 亮点 5：OBS 直播友好 + 可截取处理后的画面
Veyra 在 1.4.4 中专门处理了"OBS 采集 Veyra 视频区域黑屏"的问题，把捕获方式锁定到"Windows 10 (1903+)"，让主播可以在 OBS 里直接采集"增强后"的画面进行直播或录制。SDR 截图为 PNG，HDR 截图为 FP16 scRGB JPEG XR（保留高光浮点信息）。

## Demo 演示：5 分钟跑通第一帧 120FPS
对于普通用户，Veyra 官方推荐的"最小可跑通"流程是：
```text
1. Releases 下载 Veyra-1.4.4-win64-portable.zip
   （别下 Source code，那是依赖源码包）
2. 完整解压到可写目录，双击 Veyra.exe
   （无需装 Qt / SDK / Python，便携包内置运行时）
3. 点击底栏"打开"，加载片源 → 切到"专业模式"
4. 画质页 → 开"超分"选 4K → 开"NR"选 RTX 对应运行版本
5. 补帧页 → 选 DLSS 2X（60fps→120fps）或 XeSS
6. 全屏，享受画面
```
补帧的实际效果可以从 B 站 UP 主"公鸡咯咯大"的实测看出：用 PS5 Pro + Elgato 4K60 Pro MK.2 + RTX 5080，Veyra 2.0 开双层 DLSS5 + 补帧，**端到端延迟稳定在 32ms**，画面无果冻帧、无垃圾帧。另一位 UP 主"慈祥的儿"则反馈：之前用小黄鸭或 XeSS 补帧都有"上楼梯"伪影和果冻帧，Veyra 支持 VFG 后完全消除。
对于技术玩家，Veyra 还允许替换运行时 DLL（不锁哈希），在 `runtime/experimental/` 下可放自定义的 NR / XeSS 组件，开放性拉满。

## 上手门槛与部署体验
**部署体验：满分。** Veyra 是完全便携式，下载 zip 解压即可运行，不用装 Qt、不用装 SDK、不用装 Python。卸载就是删除目录。
**文档体验：超高。** README 同时维护中英文，docs/ 目录有数十份实测报告（如 `CAPTURE_LATENCY_FIX_2026-09-07.md`、`REMOTEPLAY_PS5_ACCEPTANCE_2026-09-11.md`），每个版本都附带 SHA-256 与第三方许可清单。
**配置学习成本：中等偏高。** 日常模式 5 步即可跑通，但要真正调好 NR 强度、保护区域、超分档位、补帧倍率，需要理解光流、神经渲染这些概念，建议先看官方"日常模式入门"教程。

**核心差异点：**

2. **NR（神经渲染）是 Veyra 独有的杀手锏。** 小黄鸭没有 NR，SVP 没有 NR，Magpie 是研究灵感来源但偏单独超分。
3. **补帧质量对比**：NGA 玩家社区横评里，小黄鸭最丝滑但烂帧多，SVP 适合动画，RIFE 伪影最少但吃资源；Veyra 因为走 DLSS FG 这条硬光流路线，在采集卡场景下"果冻帧"问题显著优于小黄鸭。
4. **价格优势碾压**：免费开源 vs SVP 的百元付费、小黄鸭的 29 元。
> **一句话定位**：如果你只是给视频文件补帧，小黄鸭更省心；如果你要接采集卡、串流 PS5、做神经渲染增强，**Veyra 没有对手**。

## 局限与不足：客观存在的问题
Veyra 不是没有短板，README 和 Release Notes 自己都列得清清楚楚。
### 1. 硬件门槛真实存在
- **主测试平台是 RTX 5070**，RTX 30/40 系要靠"社区实验版"的 NR 运行时，签名状态为 `HashMismatch`，性能与画质取决于实际显卡。
- **AMD 显卡暂无 NR 支持**，只能用 XeSS 补帧与 FidelityFX 光流，体验打折。
- **8K 超分、多层 NR、6X 补帧**对显存极敏感，1.4.4 中实测"输出上限现在决定补帧实际生成多少"，6X 在真超分档功耗从 221W 降到 174W——说明 GPU 负载非常重。
### 2. 部分功能仍属"实验级"
- **真 PS5 HDR 与 Sony 登录仍待验收**，HDR 处理本质上是"SDR 代理 + HDR 基底合成"，不是原生 HDR NR 模型。
- **真 1080p→4K 超分 + NR 下 DLSS 4X/6X 仍有长间隔**，XeSS 4X 重负载连续性问题未根治。
- **AV1 / ProRes 导出尚不支持**，XeSS 仅用于预览，导出只走 DLSS 路径。
- **NR/补帧的叠加未官方验证**，可能与 Smooth Motion 同时开启产生不可预测的副作用。
### 3. 软件形态与稳定性风险
- **便携式单机软件，无自动更新**，升级需要手动解压新目录，避免旧目录覆盖运行时组件。
- **不绑定任何官方支持**，社区 NR 二进制是修改版，NVIDIA 与 Sony 不背书，存在驱动兼容性风险。
- **衍生生态混乱**：B 站已有第三方做的"Veyra 改版 2.0"（带百度网盘下载），集成"本地游戏窗口捕获"等功能，但属于非官方魔改，安全性与稳定性自行评估。
- **强依赖特定驱动版本**，README 反复强调"使用当前显卡驱动"，旧驱动可能直接报错。
### 4. 文档虽详实，但偏硬核
中文为主、英文为辅，对非技术玩家来说，里面大量出现的"DPAPI 加密"、"WASAPI 端点"、"P010 / NV12"、"BitBlt vs WGC"等术语需要一定 Windows 媒体架构背景才能秒懂。

## 深度剖析：技术栈与架构
从公开源码组织看，Veyra 是一个相当成熟的 C++ 项目：
- **核心语言**：C++20 + Win32 + D3D12
- **解码与封装**：FFmpeg（自带 patched 版本）
- **采集**：DirectShow（支持 RGB24/32、YUY2、UYVY、NV12、P010、P016 等 15 种像素格式）
- **编码**：NVENC（视频导出走 H.264/HEVC）
- **UI**：QML（`qml/Veyra/Main.qml`、`ProPage.qml`、`NodePage.qml`、`ExportPage.qml`）
- **串流**：基于 chiaki-ng 的 PS5 Remote Play、基于 Moonlight 的 Xbox/PC 串流
- **架构核心**：一套 EnhanceGraph，多个输入源共享同一条 D3D12 处理链
```
include/veyra/
├── engine/      # 增强图、NR/SR/调色调度
├── source/      # 文件、采集卡、屏幕捕获
├── sink/        # 输出、编码与录制
├── remoteplay/  # PS5 串流
├── pipeline/    # 帧管线与帧同步
└── xbox/        # Xbox 接入
```
**许可证**：Veyra 原有源码采用 GPLv3，含串流的组合程序同时适用 AGPLv3 与上游 OpenSSL 例外。SDK、模型和运行时不进入源码仓库。
